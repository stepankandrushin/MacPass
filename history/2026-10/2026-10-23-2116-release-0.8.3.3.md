# Release 0.8.3.3

Published with `scripts/release.sh` as https://github.com/stepankandrushin/MacPass/releases/tag/0.8.3.3 (build
27070), after pushing the seven commits of main that were not on the fork yet. It carries the toolbar search field
stretched to the Lock button again, Help and the About box pointing at the fork's repository, and the plugin list
fetched from the fork instead of macpass.app. Apple's timestamp server failed several times during signing; the
script's retries got every signature through. The appcast on gh-pages names 0.8.3.3, so a3 gets it through Sparkle
once GitHub Pages has rebuilt.
